### Job Description – Senior Angular Developer at Suprz

**Key Responsibilities:**

1. **Robust State Management:**  
   - Implemented scalable state solutions using **NgRx** and **RxJS**, ensuring predictable application state with **selectors**, **reducers**, and **Store DevTools** for debugging.  

2. **Efficient Routing:**  
   - Designed **lazy-loaded routes** and **Route Guards** (CanActivate, CanDeactivate) to optimize performance and enforce security.  

3. **Modern Styling:**  
   - Applied **SCSS** with **Angular Material** for responsive UI components and **theme management** for dark/light mode support.  

4. **Performance Optimization:**  
   - Utilized **OnPush Change Detection**, **AOT compilation**, and **Pure Pipes** for faster rendering and smaller bundle sizes.  

5. **Testing Excellence:**  
   - Conducted **unit tests** with **Jasmine/Karma** and **end-to-end tests** with **Cypress** to ensure reliability and seamless user flows.  

6. **Best Practices:**  
   - Followed **Angular’s Style Guide**, **Modular Architecture**, and **Reactive Forms** for maintainable, scalable, and consistent code.  

7. **Collaboration:**  
   - Mentored junior developers, participated in code reviews, and collaborated with cross-functional teams to deliver high-quality solutions.  

8. **CI/CD Integration:**  
   - Automated testing and deployment pipelines using **GitHub Actions** for streamlined development.  

**Technologies Used:**  
- Angular 16+ | NgRx/RxJS | Angular Router | SCSS/TailwindCSS | Angular Material | Jasmine/Karma/Cypress
